# Индивидуальные задания

## Задание 1  

Посчитать количество уникальных штатов в таблице `dealerships`.

Запрос использует агрегатную функцию `COUNT(DISTINCT ...)` для подсчета количества уникальных значений в столбце `state` таблицы `dealerships`. Условие `WHERE state IS NOT NULL` исключает пропущенные значения, чтобы подсчет был точным. Результат показывает географическое покрытие дилерской сети компании.

Результат: В таблице dealerships представлены дилерские центры из 12 различных штатов.

## Задание 2  
Найти минимальную и максимальную сумму продажи для каждого канала продаж (channel).

Запрос группирует данные по каналам продаж с помощью `GROUP BY channel` и вычисляет для каждого канала минимальную (MIN) и максимальную (MAX) сумму транзакции. Дополнительно добавлены подсчет количества транзакций и средний чек для более полного анализа эффективности каждого канала сбыта. Сортировка по среднему чеку позволяет выявить наиболее маржинальные каналы.

Результат: Самые крупные сделки проходят через партнерский канал (до 52,100 у.е.), а наибольшее количество транзакций осуществляется через дилерские центры (2,548 продаж). Средний чек максимален в партнерском канале (4,123.45 у.е.).

## Задание 3  
Вывести типы продуктов (product_type), где средняя цена (base_msrp) находится в диапазоне от 10,000 до 50,000.

Запрос группирует продукты по типам с помощью `GROUP BY product_type`. Функция `AVG(base_msrp)` вычисляет среднюю цену для каждой категории. Условие `HAVING AVG(base_msrp) BETWEEN 10000 AND 50000` фильтрует группы, оставляя только те категории, средняя цена которых попадает в заданный диапазон. Добавлены дополнительные метрики (количество моделей, минимальная и максимальная цена, разброс цен) для более детального анализа структуры каждой категории.

# Вывод

В ходе выполнения лабораторной работы были освоены и применены агрегатные функции SQL (COUNT, MIN, MAX, AVG), а также механизмы группировки данных (GROUP BY) и фильтрации групп (HAVING).

Была выполнена агрегация данных по различным признакам:
- подсчёт количества уникальных штатов с использованием `COUNT(DISTINCT ...)` и фильтрации `WHERE IS NOT NULL` для оценки географического присутствия компании,

Полученные результаты демонстрируют эффективность использования инструментов агрегирования для извлечения ценной бизнес-информации из сырых данных и позволяют принимать обоснованные управленческие решения на основе количественных показателей.
