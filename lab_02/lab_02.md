# Цель работы

Освоить методы объединения таблиц (JOIN), работу с подзапросами и функции преобразования данных (COALESCE) в PostgreSQL.

# Задания

## Задание 1. Использование JOIN  
Вывести имена клиентов и даты открытия писем, если письмо было открыто.

`INNER JOIN` связывает таблицы `emails` и `customers` по идентификатору клиента. Условие `WHERE opened = 't'` фильтрует только открытые письма.

Результат выполнения: Список клиентов с датами открытия писем.

## Задание 2. Использование подзапроса 
Найти продукты, которые покупали клиенты из города 'New York City'.

Через цепочку `INNER JOIN`связываются таблицы `sales`, `products` и `customers`. Условие `WHERE` отбирает только клиентов из Нью-Йорка.

Результат выполнения: Список продуктов, купленных клиентами из Нью-Йорка.

## Задание 3. Преобразование данных (COALESCE)  
Создать столбец contact_info: если есть телефон - телефон, если нет - email.

Пояснение логики: Функция `COALESCE` возвращает первый не-NULL аргумент. Сначала проверяется наличие телефона, если его нет - подставляется email.

Результат выполнения: Контактная информация клиентов (телефон или email).
