# Цель работы

Научиться писать запросы SELECT для аналитики и выполнять CRUD операции в локальной базе данных PostgreSQL.

# Задания

## Задание 1.1  
Вывести все продажи (sales) за 2021 год.
Сортировка: дата транзакции.

Запрос отбирает все продажи за 2021 год с помощью оператора `BETWEEN` и сортирует по дате транзакции в порядке возрастания.

Результат выполнения: Все продажи, совершенные в 2021 году, отсортированные по дате.

## Задание 1.2  
Вывести дилеров (dealerships) НЕ в штатах 'CA' и 'TX'.

Оператор `NOT IN` исключает дилерские центры, расположенные в Калифорнии и Техасе, оставляя все остальные штаты.

Результат выполнения: Список дилерских центров во всех штатах, кроме CA и TX.

[Скриншот выполнения задания](https://raw.github.com/ChumakovOA/-/main/01_02.jpg)

---

## Задание 1.3  
Создать таблицу managers (продавцы-менеджеры).
Добавить поле `salary`.
Удалить записи с датой найма до 2010 года.

Сначала создается таблица `managers` путем копирования данных продавцов из `salespeople` с добавлением нового идентификатора `manager_id = salesperson_id + 1` и фильтрацией записей с датой найма после 2010 года. Затем с помощью `ALTER TABLE` добавляется поле `salary`, которое заполняется значением 65000 через оператор `UPDATE`.

Результат выполнения: Создана таблица managers с данными о продавцах, нанятых после 2010 года, добавлено поле `salary` со значением 65000 для всех записей.
